# Sinagua FTC Robot Program

This repository hosts the robot program for the Sinagua Middle School FTC robotics team.

## Who wrote what

- **Robot program:** written by the Sinagua students. It is hosted here for the team and is their work.
- **Calibration tools (Python):** written by Paul Doose, the team's mentor. These are the only parts of this repository that are his own work. They are in `[folder name]`.

## Mentoring

Paul Doose mentors the team, teaching Java basics to students for FTC competition.

## Notes

- The robot program is written in Java for the FTC competition platform.
- The calibration tools are used to calibrate the robot and are not part of the competition code.
